Rotating the admin password
$ sed -i 's/^ADMIN_PASSWORD=.*/ADMIN_PASSWORD=new-secret/' .env
$ docker compose up -d web

Existing browser sessions stay valid: the session secret is stored separately in /data/.session_secret so a container update does not sign everyone out, and it is not derived from the password. To force every session out, delete that file and restart:

$ rm data/web/.session_secret
$ docker compose up -d web
Prometheus metrics

/metrics is not public - it exposes every username and backup size. A signed-in browser session can read it; Prometheus needs a token. Set METRICS_TOKEN in .env, then:

scrape_configs:
  - job_name: timenest
    authorization:
      credentials: '<METRICS_TOKEN>'
    static_configs:
      - targets: ['timenest.local:8080']
